2. **v1's rule shape is well-designed.** Day choice robust (rank #6/25). Cost robust ($50 RT still works). 4-of-4 gate precisely calibrated (3-of-4 loses money).
3. **Ensemble is under-informative in the current regime.** Monthly M12 stuck LONG for 1,221 days makes the "3-way vote" reduce to "v1 for LONGs, v2 for SHORTs." Shadow window won't produce useful comparison data before it closes.

Future v-something-else could use RY_level as an interaction term or signal-strength scalar, not a binary filter.
